# PhiSafe

**Offline-first, privacy-first household emergency readiness.**

PhiSafe helps households prepare for common emergencies, plan safe evacuations, and maintain supplies and animal rosters. It is not an emergency-alert service, weather forecast, or substitute for official instructions.

> Status: initial repository bootstrap. The first functional application is proposed in a pull request.

## Principles

- People and animals first.
- No accounts, no trackers, no third-party APIs.
- Household records stay on the device unless deliberately exported.
- Mobile-friendly, printable, and usable after the app has been loaded and cached.
- Preparedness without fearmongering.
- Informational checklists only, never automatic orders to evacuate or shelter.

## Privacy

Do not commit real names, medical information, addresses, rendezvous locations, or phone numbers to this public repository. Personal plan data belongs in browser-local storage and backups you control. Browser storage is not encrypted.
